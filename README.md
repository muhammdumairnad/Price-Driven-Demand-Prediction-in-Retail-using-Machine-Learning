## 🧠 Overview

This project combines **Machine Learning** + **Interactive Dashboarding** to help businesses:

- 📦 Forecast product demand  
- 💰 Estimate revenue instantly  
- 🎯 Optimize pricing strategy  
- 📊 Visualize insights in real time  

Built as a production-style application using **Streamlit**.

- 🔐 Login & Signup system  
- 📊 Clean and modern dashboard UI  
- 🤖 ML-based demand prediction  
- 📈 Interactive Plotly charts  
- 🎯 Automated price optimization  
- ⚡ Real-time results

## ⚙️ Run Locally

```bash

# Navigate to the project directory
