## 📊 Price-Driven Demand Prediction in Retail using Machine Learning

## 📌 Overview

This project focuses on predicting product demand based on pricing and other influencing factors using machine learning techniques. The goal is to help retailers understand how price changes impact demand and support data-driven decisions for pricing optimization and inventory planning.

---

## 🎯 Objective

* Analyze the relationship between product price and demand
* Build predictive models to estimate demand based on price and other features
* Identify the most effective model for accurate demand forecasting
* Provide insights that can help businesses optimize pricing strategies

## 🔍 Key Insights
